# browser_click(element, ref)

Клик левой кнопкой по элементу из снимка.

| Параметр | Описание |
| --- | --- |
| `element` | Читаемое описание (для аудита и согласия, расширение его не использует) |
| `ref` | ref из последнего `browser_snapshot` |

**Как работает.**

1. Агент страницы находит элемент. Если он не целиком в окне, прокручивает его в центр и возвращает центр первого прямоугольника (для перенесённых ссылок именно его).
2. CDP `Input.dispatchMouseEvent`: `mouseMoved` → `mousePressed` → `mouseReleased`. События доверенные (`isTrusted`), как от настоящей мыши.
3. У элемента нулевого размера (скрытый чекбокс под кастомным дизайном) делается DOM `element.click()`.
4. Расширение ждёт 120 мс. Если клик запустил навигацию, оно ждёт её окончания (до 15 с), чтобы следующий снимок был уже новой страницы.

**Ошибки**: все ошибки ref из [snapshot.md](snapshot.md).

**Ограничения.** Если элемент перекрыт оверлеем, клик попадёт в оверлей, как и у настоящего пользователя. Кнопки внутри iframe недоступны. Двойной и правый клик можно сделать через [browser_cdp](cdp.md) (`Input.dispatchMouseEvent` с `clickCount: 2` или `button: "right"`).
