# browser_wait(time)

Пауза на `time` секунд (0..60). Выполняется на сервере (`asyncio.sleep`) и связь с браузером не проверяет. Значения вне диапазона сервер отклоняет.

Расширение тоже понимает команду `browser_wait` (с тем же лимитом) для клиентов, которые шлют её напрямую, но `server.py` её не отправляет.

Совет: вместо слепой паузы чаще хватает `browser_snapshot`: действия и так ждут загрузки и стабилизации DOM.
