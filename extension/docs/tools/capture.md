# browser_capture(mode="viewport", scale="original")

PNG веб-страницы через CDP `Page.captureScreenshot`.

| Параметр | Значения |
| --- | --- |
| `mode` | `viewport`: видимая область; `full_page`: весь документ (`captureBeyondViewport`) |
| `scale` | `original`: без принудительного уменьшения, в физических пикселях (с учётом DPR); `reduced`: вписать в 1024×768 |

**Лимиты.** Не больше 16 млн пикселей и 16 384 px по длинной стороне. Большие страницы пропорционально уменьшаются, чтобы уложиться. Base64 длиннее 31 млн символов отклоняется с подсказкой про `scale=reduced`, потому что сервер принимает до 32 млн.

**Не попадает в снимок**: адресная строка, вкладки, панель DevTools, системные диалоги.

**Известные особенности full_page**: фиксированные (`position: fixed/sticky`) шапки оказываются там, где стоят в текущем скролле. Lazy-loading картинки, которые ещё не проскроллили, могут быть пустыми. Страницы с `100vh`-вёрсткой могут на мгновение пересчитать разметку. Viewport вкладки не меняется.

**Проверка**: `acceptance.html` содержит длинный блок и маркер `FULL_PAGE_END_MARKER` в конце: он должен быть виден на `full_page`.
