# browser_navigate(url)

Открывает URL в подключённой вкладке и возвращает снимок новой страницы.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `url` | string | Адрес. Без схемы добавляется `https://`, для `localhost`/`127.*` добавляется `http://` |

**Как работает.** Расширение сначала подписывается на события `webNavigation`, потом вызывает CDP `Page.navigate`. Если Chrome вернул `errorText` (например `net::ERR_NAME_NOT_RESOLVED`), инструмент падает с этим текстом. Дальше расширение ждёт окончания загрузки главного фрейма (до 25 с) и стабилизации DOM (тишина 250 мс, максимум 1.5 с).

**Консоль.** Отладчик подключён до навигации, поэтому ошибки во время загрузки новой страницы попадают в журнал. Перед ними встаёт отметка `navigation`.

**Ошибки**: `url is required`, `Not a valid URL`, `Navigation to ... failed: net::...`, `No tab is connected`.

**Ограничения.** Медленная страница не считается ошибкой: через 25 с расширение отвечает, и snapshot покажет то, что успело загрузиться. На `chrome://`, `chrome-extension://`, `devtools://`, Web Store и `javascript:` инструмент отказывает сразу: такая страница выкидывает отладчик из вкладки. Если вкладка уже стоит на защищённой странице (открыли руками), navigate на обычный URL и go_back/go_forward работают через `chrome.tabs` и возвращают вкладку под управление.

`file://` по умолчанию тоже отказ: при включённом «Доступе к URL файлов» такая страница показывает ИИ любой файл компьютера в обход Local Access. Разрешить можно галочкой popup → Settings → «Allow file:// pages» **и** `"browser.allowFileUrls": true` в конфиге сервера. `javascript:1` больше не принимается за «хост:порт» (раньше превращался в `https://javascript:1`). Отказ самого Chrome (`Page.navigate: Not allowed`, например Web Store по http://) объясняется понятным текстом, вкладка остаётся на месте. Те же правила действуют для `browser_cdp Page.navigate` и для записей истории в go_back/go_forward.

```json
{"id": "…", "type": "browser_navigate", "payload": {"url": "127.0.0.1:18765/acceptance.html"}}
```
