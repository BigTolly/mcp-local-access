# Rules

## Что это за проект

- Локальный MCP-сервер: даёт внешним сервисам с ИИ (Notion AI, claude.ai, ChatGpt и другим)
  управляемый доступ к одной папке на вашем ПК.
  MCP сервер — «руки», ИИ модель сервиса — «мозг».
- Стек: Python + MCP SDK (FastMCP) + uvicorn, транспорт Streamable HTTP на `/mcp`,
  авторизация Bearer-токеном, наружу — туннель `cloudflared` или веб сервер с TLS.
- Детали по проекту в файле `README.md`.
- Источник истины по фактическому поведению — `server.py`.
  Если README и код расходятся, прав код, а README надо поправить.

## Как работать в этом проекте

- Сначала `list_files` / `search_text`, затем `read_file`, и только потом правки.
- Правки вносить самому в файлы, а не присылать код в чат.
- Точечные правки — `edit_file`; несколько замен в одном файле — одним
  `multi_edit`; переименование — `move`. Полная перезапись (`create` с
  `overwrite=true`) — только когда файл действительно переписывается целиком.
- Один файл не править параллельными вызовами: каждый читает и пишет его целиком,
  одновременные вызовы затирают друг друга.
- Меняешь поведение сервера → в том же заходе синхронизируй `README.md` и, если
  нужно, `config.example.json`.
- Проверяй путь перед `delete`: корзины нет, удаление безвозвратное.

## Чего не делать

- Не обходить `Permission denied` — это окончательный ответ, а не препятствие.
- Не пытаться расширить себе права: `config.json` закрыт правилом
  `*(**/config.json)` намеренно, права меняет только владелец.
- Не трогать секреты: `**/.env`, `**/.env.*`, `**/secrets/**`, `*.pem`, `*.key`.
  Токен из `.env` не публиковать и не коммитить.
